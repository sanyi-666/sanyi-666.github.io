在 Windows 上搭一套 Kali 与 Ubuntu 的实验环境

2026-10-25

课程要求有一个自己的 Linux 环境。虚拟机是最常见的做法， 但装 VirtualBox、下 ISO、分配内存，对一台日常还要用的笔记本来说有点重。 WSL2 是另一条路：Linux 以虚拟机的形式跑在 Windows 里， 但用起来就是一个终端窗口，文件互通、复制粘贴都正常。

先确认版本

wsl -l -v
#   NAME          STATE      VERSION
# * Ubuntu        Stopped    2
#   kali-linux    Stopped    2

VERSION 那一列是 2 就对了。也可以在实例里看内核： uname -r 带 -microsoft-standard-WSL2 就是 WSL2。

装发行版，尽量别装到 C 盘

默认安装会落在 C 盘的用户目录下，一个发行版动辄几百兆到几个 G。 装到别的盘用 --location：

wsl --install kali-linux --location D:\wsl\kali-linux

已经装好的也可以迁移，不用重装：

wsl --manage Ubuntu --move D:\wsl\Ubuntu

如果在线清单拉不下来

wsl --install 需要先访问一份发行版清单。这份清单有时连不上， 报错类似 WININET_E_CONNECTION_RESET。这时候可以用本地镜像绕过去：

wsl --install --from-file kali-linux.wsl --name kali-linux --location D:\wsl\kali-linux

镜像从发行版官方站点下，装之前记得校验一下 SHA256。 这一步多做十秒，能省掉后面排查一小时的麻烦。

装完先做三件事

  1. 建一个普通用户，别一直用 root；
  2. 把 apt 源换成国内镜像，装包会快很多；
  3. 确认 systemctl 能用（ps -p 1 -o comm= 应该输出 systemd）。
sudo apt update
sudo apt install -y build-essential python3-pip default-jdk
gcc --version; python3 --version; javac -version

三条版本号都能打出来，环境就算齐了。 之后无论是写 C、跑 Python 还是练 Java，都不用再折腾安装。
